## Implementation completed

**M01 acquisition and delivery.** Existing per-scene QA remains mandatory. Selected provider collection IDs are checked; inspected Sentinel-1, Sentinel-2 and CHIRPS IDs are pinned before compositing. Sentinel-1 baseline/target orbit compatibility and complete CHIRPS daily cadence remain enforced. Static SRTM/JRC identity, required bands and native grid metadata are inspected. ALOS retains actual native tile identity/metadata, rejects duplicate/unknown tiles and incomplete AOI footprints, and mosaics pinned tiles with an explicit native default projection. Provider metadata is snapshotted and hashed reproducibly; provider version is retained when returned, otherwise absent. No source version or provider-pixel checksum is invented.

The materialized remote stack includes the actual before/target SAR composites. Remote band names/order and downloaded GeoTIFF band descriptions/order, count, CRS/grid and existing AOI pixel masks are checked before releasing analysis arrays. Download size is bounded, nonempty and consistent with a supplied content length, and streams close on failure. ZIP members are bounded and unencrypted; corrupt/unreadable remote metadata/exports fail with an unavailable quality state. The original received export (plus extracted TIFF for a ZIP response) is retained with actual SHA-256/size. Workflow SAR-array checksums and the retained artifact inventory/byte checksums are rechecked before protected publication. Original received bytes and derived before/target composite COGs in dB carry actual grid and separate period semantics. Existing extent/vector/legend products, raw predictions and SAR pseudo-label limitations remain unchanged. COG masks use explicit nodata; original received bytes remain available independently of these presentation/export conversions.

**M11 distinct reviewed susceptibility mode.** The existing `flood_susceptibility` module now accepts optional `susceptibility_options.method_reference`. Omitted options preserve the existing relative Hazard-composite path and its explicit interpretation. The reviewed path binds historical `flood_predictor_observations` and one new `flood_predictor_raster` for every exact reviewed catalogue variable. A strict source manifest supplies binary label meanings/definition, response and predictor order, an existing classifier choice, estimator count, seed, chronological train fraction, method/version/reference, historical observation reference and the display legend. Explicit matching source-bound administrator review is required for the method, observation evidence and predictor catalogue.

The shared existing CSV join/coverage validator rejects incomplete samples, duplicated sample-variable rows, mismatched timestamp/location joins, invalid units, out-of-AOI/period data and nonfinite/constant variables. Historical coverage must precede the target period. Train/test timestamps must be disjoint; both partitions must contain both declared binary classes. Predictor definitions, units/encoding evidence and catalogue identity must match each bound raster exactly. Native projected grids and complete AOI coverage must match without resampling/imputation; predictor values outside historical training ranges fail closed. There are 10–10,000 complete historical samples and the existing bounded 25,000-cell target grid. Existing SVM training support and convergence gates remain in force.

`train_classifier_from_split` executes the explicitly selected existing classifier; no new engine, algorithm or scientific formula is added. Actual fitted estimator/configuration/library versions, learned importances where defined, model bytes, split IDs/locations/times, source-defined label meanings, training/holdout predictions and descriptive held-out diagnostics persist. Original source CSV/raster bytes, raw predictor values, raw fitted classes and unmodified conditional scores are preserved. Output units are `conditional_class_probability_0_1`, explicitly distinct from annual exceedance probability. Reviewed display breaks/colors/labels are supplied by the source; score classification follows the existing upper-inclusive display convention. No weights, labels, calibration, scientific thresholds or best model are guessed.

**M12 reviewed multi-factor zonation mode.** Optional `zonation_options.method_reference` selects a strict registered `flood_zonation_policy` CSV plus its source-bound reviewed manifest. Omitted options preserve the existing relative depth–velocity quintiles with their explicit interpretation. Only `reviewed_interval_decision_table` is supported: a supplied method/version/reference/definition, canonical factor units, consecutive supplied zone codes and distinct sourced labels/colors, and explicit AEP reference period where applicable.

The policy requires Depth and Velocity plus at least one actual Duration, AEP or Exposure Result (three to five factors). Existing protected loaders recheck project/AOI, completed task/source provenance, current approval, versions and byte checksums. Duration reuses its original verified cadence/dry-endpoint execution; Exposure reuses its approved formula/source revalidation; AEP reuses its existing strict ten-year source/result gates and requires a declared reference period preceding the analysis. No temporal frequency or probability is inferred from an event map. Canonical units are `m`, `m/s`, `hours`, `annual_probability_0_1` and `index_0_1`; exact grid/nodata and the appropriate event/reference periods are enforced.

Each rule supplies lower-inclusive/upper-exclusive intervals for every factor and one declared zone code. Rules are capped at 512 for bounded execution. Duplicate factors, contradictory classes, unsupported methods/units, overlaps anywhere in the declared factor domain and uncovered/multiply assigned AOI cells fail closed. Every supplied class has a sourced rule; classes with no observed cells are retained as zero. The decision table supplies the scientific choices; no coefficients, weights or thresholds are introduced by the implementation. Unmodified upstream factor COG bytes and unchanged approved depth × velocity outputs remain protected exports alongside the zone map. Integer zone/class COGs retain categorical nearest-neighbour overviews; raw continuous values remain float64.

**M13 shared delivery and protections.** The new map paths reuse Dataset/Task/Result storage, source snapshots, current source approval, worker publication rechecks, result authorization, cartography and reporting/export architecture. Actual CRS/datum/grid dimensions/bounds/resolution, units/nodata, source and upstream identities/versions/checksums, temporal supports, reviewed method/decision table and limitations persist. Existing generic layer/download contracts deliver sourced legends, quantitative denominators, zero classes, COG/preview, cartographic PNG/PDF and CSV/Excel/PDF/JSON/ZIP reports. The legacy products retain their interpretation; raw science is retained separately from display classification. No frontend file or generated client was changed or tested. Auth0/OIDC/BFF, tenant/membership/entitlement gates and source-bound protections remain intact.

Absent new optional manifest fields are omitted from legacy fingerprint canonicalization, preserving pre-bundle source hashes. Supplied new definitions remain checksum-pinned. Existing MLR arithmetic/selection/diagnostics are unchanged; its source observation validation is shared with M11. No dependencies or migrations were added.
